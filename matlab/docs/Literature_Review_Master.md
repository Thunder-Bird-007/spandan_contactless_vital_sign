# Spandan — Master Literature Review Index

Consolidated, project-wide index of every external paper/toolbox this project has
searched for and evaluated, across all segments, in one place — built 2026-09-20 for
review purposes (e.g. showing the course instructor what literature was consulted and
why). **This document does not replace the segment docs it summarizes** — each row
links to the segment doc with the full read, quotes, and evaluation; this is an index,
not a substitute for reading the originals.

Status legend (this project's own standing citation-verification discipline, unchanged
since Segment 10 Task 2):
- **VERIFIED-FULL** — read in full by this project.
- **VERIFIED-INDEX** — existence/authors/venue/DOI confirmed, full text not read.
- **BLOCKED** — indexed but a specific access route failed this session; a route to
  retry is recorded, never silently dropped.

Adopted/verdict legend: **ADOPTED (production default)** · **ADOPTED (gated, off by
default)** · **EVALUATED, NOT ADOPTED** · **CANDIDATE, NOT YET IMPLEMENTED** ·
**REFERENCE ONLY** (used for methodology/comparison, not a candidate to adopt) ·
**OUT OF SCOPE** (deep learning, or otherwise excluded by project scope).
