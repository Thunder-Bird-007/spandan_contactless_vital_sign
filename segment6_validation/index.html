Segment 6: Formal Validation — LOSO, Metrics & Bland-Altman

This is the documentation site for Segment 6 of the Spandan project (contactless heart-rate & SpO2 estimation from ordinary video — EEE 312 DSP Lab, BUET). Segments 2–5 built the whole measurement chain — face detection, filtering, CHROM/POS pulse extraction, FFT heart rate, and an SpO2 calibration attempt — and each produced numbers for individual subjects. Segment 6 asks the harder, more honest question across every subject at once: how good is this method really, and how do we know? It touches no video, no filter, no FFT — it pools the numbers Segments 4–5 already produced (plus the VIPL integration's extra subjects) and puts them through the same statistical machinery a real clinical validation study would use: MAE, RMSE, Pearson correlation, and Bland-Altman agreement analysis, with a genuine leave-one-subject-out (LOSO) refit for the one thing in this pipeline that's actually fitted to data — the SpO2 calibration.

The code

The actual implementation lives in the main project scaffold, not in this docs folder:

  • matlab/src/validation/computeMetrics.m — MAE, RMSE, and Pearson correlation for a pool of (predicted, ground-truth) pairs.
  • matlab/src/validation/blandAltman.m — bias line, ±1.96×SD limits of agreement, and the mean-vs-difference plot itself.
  • matlab/src/validation/runLOSO.m — leave-one-subject-out SpO2 calibration refit across the pooled UBFC+VIPL set (HR needs no equivalent — see the Guideline for why).
  • matlab/scripts/run_segment6_validation.m — the batch driver that pools whatever Segment 4/5 CSVs currently exist and runs all of the above.

What comes out of this segment

results/metrics/segment6_hr_pooled_metrics.csv — one row per (method, scope), scope in {pooled, UBFC, VIPL}. results/metrics/segment6_spo2_loso_pooled.csv — one row per subject's LOSO fold. results/metrics/segment6_spo2_loso_metrics.csv — one row per scope. As of this segment's own verification run: pooled SpO2 MAE 1.23 percentage points across 8 subjects (5 UBFC + 3 VIPL), pooled HR CHROM/POS correlation r=0.995 on the pooled VIPL subjects with a real ~4bpm average error a bare correlation number would hide. Bland-Altman figures land in results/figures/: segment6_hr_bland_altman_ {chrom,pos,green}.png and segment6_spo2_bland_altman_ pooled.png plus segment6_spo2_predicted_vs_true.png, all dataset-colored. Look at the plots before quoting any single number — with this few points, one unusual subject can visibly shift a bias line, which a bare MAE figure will not show you.
